# J&G Diamant Website + J&G OS

Produktiver Quellcode für die öffentliche J&G Website und die verbundene Kunden-/Admin-Plattform.

- `index.html` — öffentliche Website und Kalkulator
- `app.html` / `app.css` / `app.js` — J&G OS
- `assets/diamond-transparent.png` — Markenasset
- `vercel.json` — Vercel-Konfiguration

Backend: Supabase Auth, PostgreSQL und Edge Functions.
